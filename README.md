# 轻待 LightDo

轻待是 Windows 11 x64 上的本地单清单待办。把面板放在屏幕边缘，需要时呼出，写下一件事；也可以拖成悬浮窗，或固定在桌面层。

**当前为 1.0.0 本机验收候选，尚无正式 Release。** 已生成并安装候选 EXE，公开安装包将在本机关键验收完成后由标签流程构建发布。当前进度见[实施清单](docs/implementation-checklist.md)，真实结果和未验证范围见[验收记录](docs/verification.md)。

## 安装与系统要求

- Windows 11 x64，适用于 Intel / AMD。当前实际受测系统为 Windows 11 26H2，build 26300.9711；其他系统构建尚未验证，不承诺所有 Windows 11 的桌面行为相同。
- 使用 `LightDo_<版本>_x64-setup.exe`，默认按当前用户安装到 `%LOCALAPPDATA%\Programs\LightDo`，无需管理员权限。安装时可选桌面快捷方式，开始菜单中有应用和卸载入口。
- 应用不需要账号、网络、WebView2、Node.js 或独立后台服务，不含遥测、更新轮询或自动更新。正式更新由 GitHub Release 手动下载安装。
- 安装包未签名，Windows 可能提示发布者无法验证或显示 SmartScreen。不要关闭系统防护来规避提示。

## 日常操作

默认停靠主显示器右侧。将鼠标推到主屏右边缘并停留即可展开；单击输入框后输入，Enter 新增。鼠标离开并结束编辑后自动收回。首次使用有简短提示，之后也可用快捷键或托盘找回。

| 操作 | 方法 |
|---|---|
| 呼出并输入 | `Ctrl+Alt+L`，可在设置中修改 |
| 打开设置 | `Ctrl+F10`，或三点菜单 → 设置 |
| 新增任务 | 输入框中 Enter，或单击加号；空白不会新增 |
| 完成 / 取消完成 | 单击圆形按钮；任务保留原位 |
| 编辑 | 双击任务文字，Enter 保存，Esc 取消；离开编辑框提交已确认文字 |
| 列表键盘操作 | 输入框中 Tab 进入列表，方向键选任务，Space 切换完成，Enter 编辑，Delete 删除；Tab 回输入框 |
| 关闭当前交互 | Esc 先取消编辑或关闭菜单；没有内层交互时收回未固定的边缘面板 |
| 菜单 | 三点、右键面板或 F10，方向键导航，Esc 关闭 |
| 隐藏到托盘 | 标题栏 ×；它不会退出进程或清空任务 |
| 完全退出 | 托盘菜单 → 退出轻待 |

删除任务立即生效，没有任务回收站或长期删除历史。中文输入法组合期间 Enter 用于确认候选，避免把未确认文本误提交为任务。

## 窗口与外观

三点菜单按「窗口模式 / 外观 / 位置与行为」分组。设置分为「外观 / 窗口 / 通用」三页，不适用的选项会禁用。

| 模式 | 行为 |
|---|---|
| 边缘面板 | 主屏左 / 右侧停靠，支持自动收回和固定展开；默认右侧，停留约 250ms 呼出、离开约 400ms 后收回，可调整 |
| 独立悬浮窗 | 拖住标题区域离开边缘；可移动、缩放、锁定位置和切换始终置顶；拖近主屏左右边缘，按预览松手重新停靠 |
| 桌面组件 | 同一面板保持在桌面层、普通应用下面；回到桌面后可输入与编辑 |

标题栏菱形在边缘模式切换「固定展开」，在悬浮模式切换「始终置顶」，蓝色实心表示开启；桌面模式禁用。固定展开、置顶与锁定位置是不同选项。

浅色、深色、跟随系统及玻璃材质浓度可在外观中调整。默认全屏时暂停鼠标边缘呼出，快捷键仍可主动呼出；独占全屏游戏未受测。动画遵守 Windows 减少动画设置。

单实例运行，重复启动会唤起已有面板。托盘提供显示 / 隐藏、设置与返回主屏等找回入口。桌面宿主不可用时会明确提示并恢复悬浮窗，不把失败的嵌入当作成功。

## 任务保存、升级与卸载

未完成和已完成任务都会自动保存在 `%APPDATA%\LightDo\state.json`，退出、重启后继续读取。可在「设置 → 通用 → 打开 LightDo 数据文件夹」直接找到它。数据根由 Windows 用户资料位置确定，不随安装位置或启动工作目录改变；不写入源码目录，也不提供其他应用的数据导入。

读取失败会明确提示、保留原文件并禁止覆盖，短暂文件占用会先重试。若出现读取提示，请保留文件，关闭占用它的程序后重新启动；不要删除数据文件来消除提示。用户曾报告一次重开后任务不可见，原文件仍在、再启动可显示；具体触发原因尚未确认。后续补强构建已实际多次冷启动验证原任务保留，范围见验收记录。

升级前在托盘正常退出，再运行新版安装包。运行中安装会要求先退出，不强制结束应用；升级保留任务与设置。

卸载默认保留数据，重装后可继续读取。卸载向导提供主动永久删除 LightDo 任务和设置的选项；仅在确定不再需要时选择。卸载清理本应用的自启与快捷方式，不操作其他项目的数据。

## 受测范围与资源占用

已实测本机 100%、125%、150%、200% 的右边缘布局及中文候选位置。Win+D 往返、睡眠恢复、桌面组件输入和图标操作有用户手测结果。资源管理器重启、安装卸载等剩余范围见验收记录；本机仅一个物理显示器，尚未实测外接屏断开和主屏切换。

最新受测安装构建在右边缘隐藏约 39 秒，平均 CPU 约 0.012%、GPU 0%，工作集平均约 98.8 MiB、结束约 95.8 MiB。隐藏后停止背景捕获；可见玻璃仍有采集合成开销。硬件、完整测量方法、各构建哈希和限制见[资源占用记录](docs/performance.md)，不作为跨设备保证。

## 开发与发布

使用 Rust 1.99.1 MSVC、Visual Studio 2022 Build Tools 的 C++ 桌面工作负载和 Windows SDK。

```powershell
.\scripts\dev.ps1 -Isolated
.\scripts\check.ps1
.\scripts\build.ps1
.\scripts\package.ps1
```

开发隔离数据位于 `local-evidence/dev-data`；也可用绝对路径 `LIGHTDO_DATA_DIR` 指定，开发脚本结束后恢复原环境。应用本身不需要这些构建工具。

正式版本使用统一版本准备和标签发布脚本，Actions 完成检查、构建、打包、安装冒烟、完整资产下载校验后公开 Release。当前本机验收门槛仍 pending，尚不能推正式发布标签。详细步骤及失败处理见[开发与发布](docs/releasing.md)。
