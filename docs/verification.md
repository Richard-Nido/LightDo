此前锁屏阻塞已解除：用户回复桌面已解锁，WTS 复核 `lockFlag=1, locked=false`。当前 GetDpiForWindow=144（150%）。2026-10-26 用户针对 71b5f56 新版桌面模式的 Win+D 往返、添加/编辑与普通应用层级反馈「一切正常！」，该项目记为用户手测 PASS；更早旧子窗口方案的反馈仍仅作历史记录。

后续界面调整：恢复菱形快捷按钮；输入框收紧并透出真实玻璃；占位文字按原生字体行高居中；空列表只保留 14 DIP 引导。150% 实际窗口已检查三点及菱形在高亮块中的位置，关闭按钮点击后诊断 visible=false、visibleOwnedPopup=false。悬浮菱形实际点击后的 topmost 为 true → false → true。三个标题图标均按可见笔画边界居中，绘制与点击共用矩形。中文/Emoji 新增、鼠标选区和草稿跨模式/拖动保留已观察；新的透明原生编辑表面不沿用旧 IME 专项通过结论。

用户随后对本机新版手测 Enter 保存、Esc 取消、点击上方输入框失焦保存，反馈三项均正常，记为 PASS（对应任务行布局调整之前的输入实现）。同时用户报告任务文字不居中、单条任务曾抖动。已将任务文字、勾选和删除按钮按实际行高居中，原生行内编辑宽度/起点/基线与展示布局统一，背景帧刷新时不再对相同编辑几何调用 SetWindowPos；每行测量和绘制复用同一 DirectWrite 布局。退出释放当前字体句柄，避免 DPI 换字后释放旧句柄。此调整已经构建并运行；用户按物理 Esc 停止桌面控制，因此视觉和抖动消失仍为待复核，未标 PASS。

捕获补测：受控红窗设置 WDA_EXCLUDEFROMCAPTURE 后不再进入场景缩略图，WDA_MONITOR 仍保留其受保护的空内容语义；原生测试 PASS。场景测试不再打印其他窗口标题。60.83 秒场景压力测试 PASS：1192 次排列、198 次 rest、143 帧读取、3841 次受控背景重绘；没有卡死，单次排列最大 46.1 ms。它不等于长时间资源泄漏或完整桌面视觉验收。

当前构建补测：150% 实际拼音 n/i 候选窗位置正确，Space 选择“你”，Enter 新增且输入清空并保留焦点；占位字不再叠在组合文字后方。已双击“你”获得行内原生编辑控件与选区。标题拖动后的物理坐标由 [88,120,688,1020] 变为 [283,194,883,1094]，动态网格仍更新，未观察到自身递归。启动时置顶偏好曾未应用，已改用统一 show(false) 路径，重启诊断 topmost=true、foreground=false。尚未扩大为行内提交/取消、所有 DPI 或完整玻璃通过。

## 必须补齐的实际验收

- 新版浅色、深色、动态背景、圆角折射、拖动/缩放连续刷新、无自身递归与闪烁。
- 新版中文候选窗、Enter 时序、行内 Enter/失焦/Esc、选区、复制粘贴、长文本与键盘删除。
- 左右边缘防误触、延迟返回、编辑阻止收回、固定展开、锁定、置顶、全屏避让、快捷键冲突。
- 新版同一面板三种模式、拖出/重新停靠、桌面图标交互、Explorer 重启；Win+D 往返已获用户实测通过。
- 锁屏后解锁、睡眠恢复、100/125/150/200% 实际 DPI、多屏主屏切换和断开后的找回。几何单元测试仅覆盖比例计算，不能冒充这些实测。
- 设置窗口的滑块、主题、自启、快捷键和恢复默认，异常保存提示。
- 完整安装、首次启动、升级保留数据、卸载保留/删除数据、自启卸载清理。
- 资源占用、启动时间、切换泄漏、从最终 Release 下载后校验并安装；干净 Sandbox/虚拟机尚未执行。
