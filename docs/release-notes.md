# 轻待 LightDo 1.0.0

首个正式版本：纯本地单清单待办，使用真实背景玻璃，提供边缘面板、独立悬浮窗和桌面组件。

## 下载与安装

下载下方资产 **LightDo_1.0.0_x64-setup.exe**。Windows 11 x64（Intel / AMD），按当前用户安装；可选择安装位置及桌面快捷方式。应用无需账号、网络或额外WebView运行环境，不含遥测和自动更新。

升级前从托盘正常退出轻待，再运行安装包。升级保留任务与设置。卸载默认保留数据，也可主动选择永久删除。任务位于 `%APPDATA%\LightDo\state.json`，设置的“通用”页可打开实际数据文件夹。

`SHA256SUMS.txt`提供安装包及许可ZIP的SHA-256；许可ZIP、项目LICENSE、第三方声明与锁定依赖清单一并提供。请使用本次Release的校验文件，不套用开发候选的哈希。

## 使用

- 默认停靠主显示器右侧，鼠标停留呼出，离开后自动收回；支持左侧和固定展开。
- `Ctrl+Alt+L`呼出并输入，`Ctrl+F10`打开设置；快捷键可改，冲突会提示。
- 双击任务编辑，Enter保存、Esc取消。中文输入法组合受保护，完成任务保留原位。
- 菱形快捷按钮在边缘模式切换固定展开，在悬浮模式切换置顶；桌面模式禁用。
- 拖出边缘成为悬浮窗，拖近主屏左右边缘按预览松手停靠；三点菜单也可切换模式。
- 默认拖动停靠范围缩小为16，可在设置“窗口”页调整为4–96；数值越小，需更接近边缘，预览与实际停靠判定一致。
- 标题栏×隐藏到托盘，托盘“退出轻待”完全退出。任务自动本地保存，重启继续读取。

## 实际验证与限制

本机Windows 11 26H2 build26300.9711、单屏2560×1600；实际改变100/125/150/200%缩放检查右边缘布局和中文候选位置。三种模式、Win+D往返、睡眠恢复、图标操作、Explorer重启后的可用悬浮恢复，以及任务重启保留已有实际或用户手测证据。

本机安装、升级、运行中保护、默认保留卸载、主动删除卸载、自启/快捷方式清理均有记录；发布资产由标签工作流检查、构建、安装冒烟并在草稿下载校验后公开。

当前受测候选右边缘隐藏约39秒，平均CPU约0.012%、GPU0%，工作集结束约95.8MiB。可见玻璃仍有采集合成开销；不是跨设备或全天无泄漏保证。

安装包**未签名**，Windows可能显示发布者验证或SmartScreen提示。其他Windows 11构建、外接屏断开/主屏切换、独占全屏游戏和注销后自启尚未实际验证。资源管理器重启时允许明确恢复为悬浮窗；可从菜单重新切回桌面组件。显示器、第三方桌面软件和显卡驱动差异可能影响背景采样或桌面层级，失败时应显示降级状态。
