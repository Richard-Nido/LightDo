系统要求：Windows 11 x64（Intel / AMD）；最低实际受测版本以本次 verification.md 为准。

下载 `LightDo_<version>_x64-setup.exe`，安装到当前用户。升级保留任务与设置；卸载默认保留数据，可主动选择删除。任务与设置位于 `%APPDATA%\LightDo\`。无需账号，不联网，不含遥测或自动更新。

安装包未进行代码签名，Windows 可能显示发布者验证或 SmartScreen 提示。

本次变化、测试环境与已知限制见源码中的 CHANGELOG.md 和 docs/verification.md。没有将未验证的桌面行为标记为通过。
