# 后续确认的产品要求

用户在 2026-10-26 明确要求：轻待是独立新项目，不需要「导入 QuietDo」。此决定覆盖初始 Prompt 中有关数据导入的条款。

- 删除导入菜单、导入命令、其他应用数据路径和导入模型逻辑，不提供首次启动导入询问。
- 只维护轻待自己的本地任务和设置；旧开发版轻待数据中的废弃导入偏好可被忽略，不丢失已有任务。
- 上游来源追踪及许可证继续保留，与产品的数据导入能力无关。

同日后续界面要求：

- 保留标题栏菱形快捷按钮：悬浮模式切换「始终置顶」，边缘模式切换「固定展开」；桌面模式显示禁用状态，避免破坏桌面层级。实心蓝色表示已开启。
- 输入区域使用透出实际玻璃的浅色圆角表面，收紧到 40 DIP；占位文字与原生输入行按字体实际行高垂直居中。实际文本、选区、光标与 IME 仍由 Windows 原生编辑控件处理。
- 删除「给此刻，留一点轻盈」文案；空列表仅保留 14 DIP 的「在上方写下第一件事」。
- 三点、菱形与关闭按钮统一使用 32 × 32 DIP 高亮块，图标按实际可见笔画边界居中；点击区域在同一矩形四周各扩展 4 DIP。
- 正常状态不在左下角显示「悬浮窗」等模式文字，保持界面简洁。
- 任务文字保持左对齐，按每行实际高度垂直居中，勾选与删除按钮共用行中心。编辑前后使用相同的文字宽度、起点和基线；排查单条任务偶发抖动，不以其他任务正常代替该问题复核。

最终交付完成后清理工作目录：保留可维护的源码、锁文件、正式安装包、许可、使用文档与必要验收结论；删除不再需要的构建缓存、临时测试数据、工具下载缓存和废弃实验文件。清理在验收及发布完成后进行，不删除用户自己的任务数据或项目外文件。
